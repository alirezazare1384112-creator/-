# 🤖 راهنمای نصب ربات ۲۴ ساعته توییتر → تلگرام (GitHub Actions)

این پکیج باعث می‌شود توییت‌های ۹ اکانت، **۲۴ ساعته و بدون وابستگی به هیچ چتی**،
به‌صورت خودکار ترجمه و با عکس به کانال تلگرامی «جنگ» ارسال شود.

- ✅ رایگان (حساب GitHub رایگان کافی است)
- ✅ هر ۵ دقیقه چک می‌کند (ممکن است گاهی چند دقیقه تأخیر داشته باشد)
- ✅ نیازی به کامپیوتر روشن یا سرور ندارد — روی سرورهای GitHub اجرا می‌شود
- ✅ همان فرمت پیام‌های فعلی کانال (نام اکانت + متن اصلی + ترجمه + عکس + لینک)

## 📦 فایل‌های پکیج

```
monitor.py                              ← اسکریپت اصلی
.github/workflows/telegram-monitor.yml  ← فایل زمان‌بندی GitHub Actions
```

## 🔧 مراحل نصب (حدود ۱۰ دقیقه، فقط یک‌بار)

### ۱. حساب GitHub بسازید (اگر ندارید)
به [github.com](https://github.com) بروید و ثبت‌نام کنید (رایگان).

### ۲. یک مخزن (Repository) خصوصی بسازید
- روی دکمه سبز **New** (یا + در بالا) کلیک کنید
- اسم بگذارید مثلاً `tweet-monitor`
- **Private** را انتخاب کنید (خیلی مهم!)
- **Create repository** را بزنید

### ۳. فایل `monitor.py` را آپلود کنید
- در صفحه مخزن، روی **Add file → Upload files** کلیک کنید
- فایل `monitor.py` را بکشید و رها کنید
- **Commit changes** را بزنید

### ۴. فایل Workflow را بسازید
- دوباره **Add file → Create new file** کلیک کنید
- در کادر نام فایل، این مسیر را **دقیقاً** تایپ کنید:
  ```
  .github/workflows/telegram-monitor.yml
  ```
  (تایپ `/` بعد از هر پوشه، خودکار پوشه می‌سازد)
- محتوای فایل `telegram-monitor.yml` از این پکیج را کپی کرده و در آنجا Paste کنید
- **Commit changes** را بزنید

### ۵. اولین اجرا (تست)
- به تب **Actions** مخزن بروید
- اگر پاپ‌آپ فعال‌سازی آمد، روی **Enable workflows** کلیک کنید
- از لیست سمت چپ، **Twitter Monitor** را انتخاب کنید
- روی **Run workflow → Run workflow** (دکمه خاکستری سمت راست) کلیک کنید
- اجرا سبز شد = همه‌چیز درست است ✅

### ۶. تمام! 🎉
از این به بعد هر ۵ دقیقه خودکار اجرا می‌شود. **دفعه اول فقط state را ثبت می‌کند
و چیزی نمی‌فرستد** — از توییت بعدی به بعد، پیام‌ها به کانال می‌آیند.

## ⚠️ نکات مهم

1. **جلوگیری از پیام تکراری:** تا وقتی این پکیج را نصب نکرده‌اید، پایش داخل
   چت ز.ای هم فعال است. **بعد از نصب و تست موفق، در چت به هوش مصنوعی بگویید
   «دمان داخلی رو خاموش کن»** تا پیام‌ها دوباره ارسال نشوند.

2. **توکن بات داخل `monitor.py`** هاردکد شده است (خط `BOT_TOKEN`). چون مخزن
   Private است فقط خودتان می‌بینید. اگر خواستید امن‌تر باشد، می‌توانید آن را
   به Secrets مخزن منتقل کنید (Settings → Secrets → Actions →
   `TELEGRAM_BOT_TOKEN`) و در `monitor.py` بخوانید.

3. **افزودن اکانت جدید:** در `monitor.py` لیست `ACCOUNTS` را ویرایش کنید
   (ایمیل‌آدرس GitHub خود را لازم ندارد؛ مستقیم از صفحه مخزن قابل ویرایش است
   با آیکون مداد ✏️).

4. **تغییر فاصله چک:** در فایل `telegram-monitor.yml` مقدار cron را تغییر دهید
   (فرمت: `دقیقه ساعت روز ماه روزِهفته`). حداقل ۵ دقیقه توصیه می‌شود.

## 🔍 عیب‌یابی
- تب **Actions** → روی اجرای قرمز کلیک کنید → لاگ کامل را ببینید
- خطای «profile fetch error» = موقت بود x.com؛ اجرای بعدی درست می‌شود
- اگر توکن بات تغییر کرد، همان را در `monitor.py` عوض کنید
